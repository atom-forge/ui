# AtomForge UI guide

> [!tip] Live examples
> Browse the components running live at [atom-forge.eu/ui](https://atom-forge.eu/ui/).

This book explains **how to think about** `@atom-forge/ui`: what the library is, how its pieces fit together, and where the usual mistakes are. It is a reading path, not a reference.

The reference lives in `docs/` and is embedded into the chapters instead of being copied, so each topic has one source. Useful entry points:

- [Component Overview](https://github.com/atom-forge/ui/blob/main/docs/guides/component-overview.md) — capability map and category index
- [Control documentation](https://github.com/atom-forge/ui/blob/main/docs/guides/component-overview.md#category-index) — props, behavior, and limitations per control
- [Composition guides](https://github.com/atom-forge/ui/blob/main/docs/guides/forms.md) — forms, overlays, data display, sortable lists

> [!note] Book and reference
> When this book and a control's documentation disagree, the control documentation wins. Open an issue or fix the book.

Start with [[book/01-overview]].
