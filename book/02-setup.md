# Setting up a project

Setup has four steps: requirements, install, CSS, and the `Root` layout. The sections below come straight from the [Getting Started](https://github.com/atom-forge/ui/blob/main/docs/guides/getting-started.md) reference.

> [!warning] Missing styles
> Tailwind 4 does not scan `node_modules`. If components render unstyled or partially styled, the `@source` line for the library is almost always what is missing.
