## Request

Close Modal/Drawer overlays on route navigation, and describe how that lifecycle behavior should work.

## What Was Done

- Added `OverlayStackManager.closeAll()` so the shared Modal/Drawer stack can resolve and clear every active overlay at once.
- Added immediate popup cleanup support in `PopupManager.resolve()` for pending delayed opens and delayed closes.
- Wired `Root.svelte` to SvelteKit `beforeNavigate()`, clearing the shared Modal/Drawer stack and root popup before route changes render.
- Updated Modal, Drawer, and Popup docs to document navigation cleanup behavior.

## Notes

- Navigation cleanup resolves pending Modal, Drawer, and Popup promises with `undefined`.
- `closable: false` is ignored for navigation cleanup because it only controls user dismissal, not lifecycle cleanup.
- Toast notifications intentionally remain visible across navigation.
