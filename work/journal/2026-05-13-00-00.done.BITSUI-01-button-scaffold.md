## Technical Notes

### Mappastruktúra

```
src/lib/ui/
  index.ts                        ← export const UI = { Button, ... }
  general/
    button/
      Button.svelte
      index.ts                    ← export { default as Button } from './Button.svelte'
```

### Button API (teljes megtartás a jelenlegi docs alapján)

**Content:** `label: string`, `icon: IconDefinition`, `endIcon: IconDefinition`, `children: Snippet`

**Variánsok** (boolean flag-ek, első igaz nyer — `destructive › secondary › ghost › link › muted › accent › primary`):
`destructive`, `secondary`, `ghost`, `link`, `muted`, `accent` — default: primary

**Style modifier:** `outline: boolean` — bármely solid varianst bordered+transparent-re vált; `ghost`/`link`-re nincs hatása

**Méretek** (`XOR`, `variantMap`-pel): `compact` (h-8, text-xs), `small` (h-6, text-xs), `micro` (h-5, text-[10px]); default: h-10, text-sm

**Modifiers:** `pill: boolean`, `grow: boolean`, `borderless: boolean`

**State:** `disabled: boolean`, `loading: boolean | number` — `true` → spinner + disabled; `number` (0–100) → progress bar fill + spinner + label

**Events & styling:** `onclick: (e: MouseEvent) => void`, `class: string` (twMerge)

**Icon-only:** ha csak `icon` van megadva (nincs `label`, `endIcon`, `children`) → automatikusan square button

**Animációk:**
- Click pulse: `button-outline-fade-out` CSS animáció (ring fade-out) minden klikknél
- Press/release: `scale-95` mousedown-ra, elastic bounce releasekor
- ButtonBar kontextusban és `disabled` állapotban mindkettő letiltva

### Import convention

A `Button.svelte`-ben nincs bits-ui primitív szükség. Követi a jelenlegi ui-lib-dev szabályokat:
- `twMerge` class merge-re
- `XOR` + `variantMap` méretkezelésre
- `ClassProp` + `AnyProp` a `class` prop kezeléséhez
- Relative importok, soha nem `$lib`

### Dev route

`src/routes/ui/+page.svelte` — relative import: `import { UI } from '../../lib/ui/index.js'`

A route demonstrálja:
- Összes variáns (primary, secondary, destructive, ghost, link, muted, accent)
- Outline modifier kombinációkban
- Méretek (normal, compact, small, micro)
- Icon, endIcon, icon-only (square)
- loading={true} és loading={number}
- disabled
- pill, grow, borderless

## Implementation Log

### Scaffold döntések
- `src/lib/ui/` jött létre mint a bits-ui alapú komponensek párhuzamos mappája — `controls/` érintetlen
- `src/lib/ui/index.ts` exportálja a `UI` named object-et; a főindex ezt re-exportálja

### Button implementáció
- A Button nem igényel bits-ui primitívet — az implementáció azonos a jelenlegi `controls/general/button/Button.svelte`-vel, átírt relative path-okkal
- Az `Icon` és `Spinner` helper a meglévő `controls/general/icon` és `helpers/Spinner.svelte`-ből jön — mindkettő shared utility, nem fog változni
- A docs-ban említett click pulse / press-release animációk a jelenlegi implementációban sem léteznek; nem kerültek be
- `onclick` default parameter neve `_event`-re változott (unused variable lint warning elkerülése)

### bits-ui dependency
- `bits-ui@2.18.1` telepítve — `bun add bits-ui`; még nem használja a Button, de az infrastruktúra kész
