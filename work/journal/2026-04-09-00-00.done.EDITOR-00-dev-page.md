### 2026-04-09

**`work/contribution/rules/ui-lib-dev.md` updated** — Added explicit allowance for `src/routes/` as dev-only sandboxes. These are never exported from `src/lib/index.ts` and not included in the published package.

**`src/app.html` created** — Required SvelteKit HTML shell. Includes no-flash dark mode init script that reads `localStorage('dark')`.

**`src/routes/+layout.svelte` created** — Wraps all dev routes with `Root` (theme provider). Uses relative imports (`../lib/...`) instead of `$lib` alias because the project tsconfig overrides `$lib` paths for a different purpose; `$lib` is unavailable in routes.

**`src/routes/editor/+page.svelte` created** — Dev sandbox scaffold. Contains:
- Pre-wired `markdown` / `savedMarkdown` `$state` for load/save round-trip.
- Placeholder `<textarea>` where the new `Editor` component (`src/lib/controls/forms/block-editor/`) drops in during Phase 1.
- Plugin stub list pre-populated with `youtube` and `gallery` entries, ready for Phase 4.
- Save/Reset buttons exercising the round-trip.

**Note:** The existing `BlockEditor` at `src/lib/controls/editors/block-editor/` is a separate, unrelated component. This plan builds a new `Editor` at `src/lib/controls/forms/block-editor/`.
