## Request

Add an option to Select for hiding the keyboard hints.

## What Was Done

- Added the `hideKeyboardHints` prop to `Select`.
- Forwarded the prop through `SelectDropdown` to the shared `SelectPopup` helper.
- Documented the new prop and its usage.
- Fixed Select's base radius class so consumer-provided `rounded-*` classes override it.
- Kept the dropdown list unhighlighted until keyboard navigation begins.
- Added a shared `button` trigger API for Select and MultiSelect.

## Notes

The default remains unchanged: keyboard hints are visible unless `hideKeyboardHints` is set.
