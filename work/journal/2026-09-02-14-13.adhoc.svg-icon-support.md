## Request

Allow `Icon` to render inline SVG markup and SVG URLs, with color customization available only for inline SVG.

## What Was Done

- Added `svgIcon(string)` and `svgIcon(URL)` factories with distinct `InlineSvgIcon` and `SvgIcon` return types.
- Extended `IconDefinition` and `defineIcon()` so both SVG icon definitions are accepted across icon-consuming controls.
- Added inline SVG and SVG URL render paths to `Icon`.
- Documented the new API and corrected the documented `IconDefiner` stroke modifier name to `setStroke()`.

## Notes

Inline SVG markup is rendered with `{@html}` and must therefore be trusted or sanitized by the caller. URL-based SVGs render as `<img>` elements and intentionally do not expose `color()`.
