## Description

Három toggle primitív megvalósítása bits-ui alapon: `Checkbox`, `Radio` (RadioGroup + RadioButtonView), `Switch`. Ezek az első komponensek ahol bits-ui ténylegesen értéket ad: a11y (aria-checked, aria-disabled, keyboard nav) bits-ui-ra delegálva.

### import convention

```ts
import * as BitsUI from "bits-ui";
```

### Checkbox API

**Checkbox props:** `value: boolean` / `checked: boolean` (bindable, mutuálisan kizáró), `onchange: (checked: boolean) => void`, `label: string`, `disabled: boolean`, `primary` / `accent` (color variant, XOR), `compact` / `small` (XOR), `group: string`, `master: boolean`

**CheckboxView props:** `status: 'checked' | 'some' | 'unchecked'`, `label: string`, `disabled: boolean`, `primary` / `accent`, `compact` / `small`, `onclick: (e: MouseEvent) => void`

**CheckboxGroupManager:** context provider komponens + `createCheckboxGroupManager()` function. Csoport logika:
- `master` checkbox: indeterminate ha csak néhány checked, checked ha mind, unchecked ha egyik sem
- Kattintás master-en (mixed/unchecked) → mind checked; (all checked) → mind unchecked
- Checkbox-ok onMount regisztrálják magukat, onDestroy leiratkoznak

**Color variants:**

| Variant | Checked box |
|---|---|
| default | `bg-control-v border-base-b text-control-c` |
| `primary` | `bg-primary border-primary text-primary-contrast` |
| `accent` | `bg-accent border-accent text-accent-contrast` |

**Méretek:** normal (w-5 h-5), compact (w-4 h-4 text-sm), small (w-3.5 h-3.5 text-xs)

### Radio API

**RadioGroup props:** `value: any` (bindable), `size: 'normal' | 'compact' | 'small'` (default normal, context-en át adja tovább), `primary` / `accent` (XOR, context-en át), `class: string`

**RadioButtonView props:** `value: any`, `label: string`, `disabled: boolean`, `class: string`

### Switch API

**Switch props:** `value: boolean` / `checked: boolean` (bindable, mutuálisan kizáró), `onchange: (checked: boolean) => void`, `label: string | { on: string; off: string }` (string | object — crossfade animáció az on/off label közt), `icons: { on: IconDefinition; off: IconDefinition }` (csak normal méretben jelenik meg), `disabled: boolean`, `compact` / `small` (XOR), `class: string`

**Méretek:**

| Size | Track | Thumb |
|---|---|---|
| normal | `w-11 h-6` | `h-5 w-5` |
| compact | `w-9 h-5` | `h-4 w-4` |
| small | `w-7 h-4` | `h-3 w-3` |

Icons csak normal méretben látható.

### UI object frissítés

```ts
export const UI = {
  Button,
  Checkbox, CheckboxView, CheckboxGroupManager,
  RadioGroup, RadioButtonView,

```

### Dev route kiegészítés

A `/ui` route-ra kerül:
- Checkbox: standalone (default/primary/accent), méretek, disabled, group+master
- Radio: horizontal és vertical layout, color variants
- Switch: basic, on/off label, icons, méretek, disabled

## Implementation Log

### Checkbox
- `BitsUI.Checkbox.Root` van a `Checkbox.svelte` alapja — keyboard nav, ARIA, focus bits-ui-tól
- `checked` és `indeterminate` **két külön prop** bits-ui-ban (nem `boolean | 'indeterminate'`)
- `CheckboxView` megtartja az eredeti `<div role="checkbox">` megközelítést — az `aria-checked="mixed"` indeterminate state-hez bits-ui Checkbox.Root nem nyújtott megfelelő támogatást
- Group/master logika saját `CheckboxGroupManager` class-ban marad — bits-ui nem ad group management primitívet

### Radio
- `BitsUI.RadioGroup.Root` + `BitsUI.RadioGroup.Item` alapja a két komponensnek
- A saját `RadioGroupManager` context csak a size/variant adatokat hordozza — a value binding bits-ui-on keresztül megy

### Switch
- `BitsUI.Switch.Root` + `BitsUI.Switch.Thumb` — animáció, ARIA bits-ui-tól
- `value`/`checked` dual-binding és `onchange` callback megmarad

### Struktúra
- `src/lib/ui/` flat struktúra: `button/`, `checkbox/`, `radio/`, `switch/` — nincs `general/`/`forms/` alkönyvtár
- Dev route-ok szétválasztva: `/ui` index, `/ui/button`, `/ui/checkbox`, `/ui/radio`, `/ui/switch`
