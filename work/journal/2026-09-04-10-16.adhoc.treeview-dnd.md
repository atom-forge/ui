## Request

Add drag-and-drop tree reordering to TreeView, including kind rules, maximum depth validation, and a development demo.

## What Was Done

- Added optional TreeView DnD configuration and move types.
- Added structural validation for cycles, no-op moves, allowed child kinds, and maximum subtree depth.
- Added the `/ui/tree` development demo with local move-state handling, locked-node validation, and reset support.
- Updated TreeView documentation and the UI route index.

## Notes

TreeView keeps ownership of data with the consumer. The `onMove` callback receives the validated source and destination coordinates and must apply and persist the change.
