# Todo: Block Editor — Plugin System

## Source / Context
work/plan.editor.md — Phase 4

## Description
Implement a plugin system so non-text block types (youtube, gallery, etc.) are registered externally. The core editor has no knowledge of specific types beyond `text`.

## Technical Notes
- Plugin `parse` maps raw block content string → metadata object
- Plugin `serialize` maps metadata → raw Markdown string
- Core editor never imports plugin-specific logic

## Implementation Log

### 2026-04-11

**Plugin block detection via `block:<type>` prefix** — `detectType()` was extended to check for `block:<type>` on the first line before any other heuristic. This maps cleanly to the existing type dispatch without any change to the serialization path (`b.content` is preserved as-is).

**`BlockPlugin<M>` uses `any` default** — the generic `M` parameter defaults to `any` (matching the existing `Block.metadata: any` pattern). Plugin arrays are heterogeneous (`BlockPlugin[]`) and the editor does not need to know M — it calls `plugin.parse(block.content)` and passes the result to the component as `metadata`. No unsafe casts needed in the template.

**Metadata computed at render time, not stored** — `block.metadata` is never mutated by the plugin system. Instead, `plugin.parse(block.content)` is called inline in the `{#each}` block via `{@const meta = plugin.parse(block.content)}`. This keeps plugin parsing free of reactivity side-effects and avoids stale metadata issues.

**Plugin blocks are non-editable** — plugin block divs render the component with `data-block-id` for DOM queries but without `contenteditable`. Keyboard navigation (ArrowUp/Down/Left/Right, Backspace, Delete) in adjacent text blocks continues to work via the existing `getBlockEl()` lookups. Plugin blocks are included in the `blocks` array and serialized normally (their `content` string is preserved untouched).

**`youtubePlugin`** — parses `block:youtube\n<url>`, extracts video ID via regex, embeds via `<iframe src="https://www.youtube.com/embed/<id>">`. Falls back to an inline error span for invalid URLs.

**`galleryPlugin`** — parses `block:gallery\n<url1>\n<url2>...`, renders `<img>` elements in a flex row. Falls back to a muted error span if no URLs are present.

**Exports** — `youtubePlugin` and `galleryPlugin` are re-exported from `block-editor/index.ts`, which is already re-exported from `src/lib/index.ts`.

**`bun run check`** — 0 errors, 0 warnings.
