# Ad-hoc Work Log Workflow

## Extensions & Modular Procedures
Before proceeding, you **MUST** read and apply all extension documents matching:
👉 `work/contribution/sop-ext.log-adhoc.*.md`

## When to log?
Only when the change has architectural significance: it affects module structure,
naming conventions, the API, or has downstream impact on other files.
Trivial UI or copy changes do not need to be logged.

## Steps
1. **Do the work.**
2. **Decide:** does this have architectural significance?
3. **If yes, create a file in `journal/`:**
   `YYYY-MM-DD-HH-MM.adhoc.change-name.md`
